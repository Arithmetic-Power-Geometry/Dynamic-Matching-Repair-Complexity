# Real-data protocol\n\nExternal temporal graphs are replayed without changing algorithm code. Native insertion/deletion streams use `--mode native`. Interaction-only temporal datasets use `--mode window`; these deletions are derived expirations and must never be described as observed deletion events.\n\nPrimary metrics are update-only wall time, total instrumented work, median/p95/p99/max work, recourse, and maximality. Dataset parsing and correctness validation are outside measured update time.\n\nStart with a small temporal network for debugging, then run established DynMatch/KONECT datasets and an independent SNAP/TGB family. Preserve chronological order and report any filtering, deduplication, self-loop removal, window duration, and event limit.\n
