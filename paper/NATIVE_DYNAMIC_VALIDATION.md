# Native fully-dynamic validation\n\nThe primary external fully-dynamic benchmark is Dynamic Simple Wiki from the DynGraphLab repository. It contains genuine insertion/deletion operations and therefore requires no synthetic expiration rule.\n\nThe parser accepts the documented DynMatch sequence format: first line `# n updates`; update rows `1 u v` for insertion and `0 u v` for deletion.\n\nProtocol: first replay a bounded prefix as a parser/correctness gate; then replay the full sequence; finally run the identical sequence through native DynMatch algorithms. Report DMRC instrumented work separately from native DynMatch runtime.\n
