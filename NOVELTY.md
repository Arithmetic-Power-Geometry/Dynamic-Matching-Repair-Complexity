# Novelty audit — Dynamic Matching Repair Complexity

## Verified neighboring results

### Fully dynamic maximal matching
- Baswana–Gupta–Sen: randomized expected amortized O(log n) under the classical randomized setting.
- Bernstein–Bhattacharya–Kiss–Saranurak (STOC 2025): first deterministic sublinear update time, ~O(n^(8/9)) amortized; randomized adaptive-adversary ~O(n^(3/4)).
- Chuzhoy–Khanna–Song (STOC 2026): deterministic n^(1/2+o(1)) amortized update time using a subgraph system for verification and maintenance of maximality.

### Dynamic set intersection
The generic primitive
    maintain active set U and query N(v) ∩ U for a witness
is a dynamic set-intersection witness problem. Kopelowitz–Pettie–Porat already give dynamic witness structures and conditional square-root-type tradeoffs. Therefore the primitive itself is not a novelty claim.

### Sensitivity / recourse / affected regions
Matching sensitivity, matching recourse, vertex-update models, and affected-path dynamic matching are established topics. They must not be presented as new merely under repair terminology.

## Surviving research question

The candidate gap is narrower:

> The active-set changes and neighborhood-witness queries generated by maximal-matching maintenance are not arbitrary dynamic set-intersection operations. Does this matching-induced structure admit provably cheaper verification/repair than generic witness search, or can generic lower-bound instances be embedded despite those constraints?

This yields two legitimate outcomes.

1. **Algorithmic separation.** Exploit matching-induced restrictions to obtain an instance-sensitive or restricted-sequence data structure with a provable advantage.
2. **Hardness transfer.** Construct a reduction showing that even matching-induced witness sequences can encode a hard dynamic set-intersection instance, explaining a barrier for a defined algorithmic model.

## Claims currently safe

- Output recourse and discovery/maintenance work are different empirical quantities.
- Generic neighborhood-witness maintenance has known square-root-type tradeoffs/lower bounds.
- Current deterministic adaptive-adversary maximal matching has n^(1/2+o(1)) amortized update time.
- It is an open research task in this repository to determine whether the numerical similarity reflects a reducible lower-bound mechanism.

## Claims NOT yet safe

- “We prove a sqrt(n) lower bound for dynamic maximal matching.”
- “Repair discovery complexity is a new complexity measure.”
- “Heavy/light witness maintenance beats the 2026 state of the art.”
- “The repository implements the STOC 2026 algorithm.”
- “Observed benchmark speedups imply asymptotic improvement.”
